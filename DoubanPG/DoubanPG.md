# DoubanPG 豆瓣电影分级、搜索、跳转

修改自 https://greasyfork.org/zh-CN/scripts/429162-豆瓣电影分级 ，增加会剧透的分级描述，兼容豆瓣助手，增加电影站与豆瓣的相互跳转。

## 匹配网站

| 类型 | 网站 |
| :--: | :-- |
| 豆瓣电影 | `movie.douban.com/subject/*` |
| 影视资源站 | `hao6v.cc`、`6vdyy.com`、`6v520.cc`、`6v520.com`、`6vdy.cc`、`6vw.cc`、`dygod.net`、`xiaopian.org`、`xiaopian.com` |

## 功能说明

### 1. 恢复并增强 IMDb 链接

- 豆瓣电影详情页的 IMDb ID 由纯文本恢复为可点击的超链接
- 兼容「豆瓣助手」插件：已是超链接则不重复处理

### 2. IMDb 家长指引（分级）

从 IMDb 获取电影的家长指引评级，展示在豆瓣页面信息栏。

**分级分类**（5 大类 + 剧透）：

| 分类 | 说明 |
| :--: | :-- |
| 性爱和裸体 | NUDITY |
| 暴力和血腥 | VIOLENCE |
| 粗言俗语 | PROFANITY |
| 酒精毒品和烟草 | ALCOHOL |
| 恐怖和紧张场景 | FRIGHTENING |
| 剧透 | SPOILERS（仅 API 方式可获取，默认折叠） |

**评级严重程度配色**：

- 无：灰色
- 轻微：绿色
- 中等：橙色
- 严重：红色

**双数据源获取策略**（可在油猴菜单中切换，默认 API）：

| 获取方式 | 特点 |
| :--: | :-- |
| GraphQL API | 单次请求获取全量条目（含剧透），效率高 |
| HTML 页面解析 | API 失败时自动降级；剧透内容需点击才加载，故拿不到剧透 |

API 端点为 IMDb 网页版自用的 GraphQL 接口，请求需带 `Referer` 和 `x-imdb-client-name: imdb-web-next` 头，否则会被 CloudFront 以 403 拦截（IMDb 调整校验规则时此处需同步更新）。

**附加信息**：

- MPA 美国电影协会评级（含评级理由）
- 各国/地区分级信息汇总（点击展开）

**容错机制**：

- HTML 解析最多自动重试 2 次
- 返回 202 时判定为 AWS WAF 人机质询（需浏览器执行 JS 换取 token，脚本请求无法通过），停止重试并提示先点击【直达】打开 IMDb 页面
- API 失败自动降级为 HTML 解析，仍失败则提示手动重试
- API 返回数据、非 200 响应体均输出到控制台，便于排查请求头失效或字段结构变化

### 3. 侧边栏影视资源快速搜索

在豆瓣电影页右侧边栏添加「影视资源」分类，提供以下站点的一键搜索：

- 奈飞工厂
- iKanBot
- 七味
- 厂长资源
- BTNULL
- 搜片

搜索关键词根据站点要求自动选择中文名、GBK 编码中文名或英文片名。

### 4. 影视站 → 豆瓣搜索跳转

在支持的影视资源站浏览时：

- 页面标题旁添加「豆瓣搜索」文字链接
- 页面中央添加悬浮圆形按钮，点击跳转豆瓣搜索
- 自动从标题中提取《》或【】包裹的片名进行搜索
